# Contribution au Projet

Merci de votre intérêt pour ce projet ! Voici quelques directives pour contribuer :

1. **Signaler des Bugs :** Utilisez les "Issues" de GitHub pour signaler tout problème.
2. **Proposer des Améliorations :** Ouvrez une "Issue" pour discuter des changements majeurs avant de soumettre une Pull Request.
3. **Pull Requests :**
   - Créez une branche pour votre fonctionnalité (`git checkout -b feature/ma-fonctionnalite`).
   - Commitez vos changements (`git commit -m 'Ajout d'une fonctionnalité'`).
   - Poussez la branche (`git push origin feature/ma-fonctionnalite`).
   - Ouvrez une Pull Request.

## Standards de Code
- Suivez les conventions PEP 8 pour le code Python.
- Documentez les nouvelles fonctions et classes.
- Assurez-vous que les tests (si présents) passent.
