# Politique de Sécurité

## Versions Supportées

Actuellement, seule la branche `main` est activement supportée.

## Signaler une Vulnérabilité

Si vous découvrez une faille de sécurité, merci de ne pas ouvrir d'Issue publique. Envoyez plutôt un e-mail à l'auteur ou utilisez la fonction de signalement privé de GitHub si disponible.

Nous ferons de notre mieux pour répondre rapidement et corriger le problème.
